# 🎨 Prompt Desain Marketing — Pentol PK Bandara

> **Catatan:** untuk gambar yang ada **tulisannya**, generator paling jago =
> **Ideogram**, **DALL·E 3 (ChatGPT)**, atau **Gemini**. Kalau hasil tulisannya
> berantakan, generate gambar/background-nya aja, lalu tambah teks + QR di **Canva**.

## 🎯 Brand Kit (tempel di tiap prompt biar konsisten)
- Warna: merah `#B82F11`, terakota `#CC7D57`, oranye `#E38A3C`, cokelat `#603123`, krem `#EFECDE`
- Karakter: **kartun penjual pentol berlari** — pakai peci/topi, celemek oranye, gendong kotak gerobak di punggung, bawa mangkuk pentol berkuah (dari logo)
- Tema: **bandara / penerbangan** (sentuhan halus: pesawat kecil, garis landasan)
- Nama usaha: **Pentol PK Bandara**
- Tagline: **"Pentol Express — siap meluncur ke lokasimu!"**

---

## 1) 📱 WhatsApp Status / Broadcast (potret 9:16)
```
Poster makanan vertikal 9:16 untuk WhatsApp Status, gaya kartun modern yang
menggugah selera. Karakter maskot penjual pentol lucu sedang berlari sambil
membawa mangkuk pentol bakso berkuah panas mengepul dengan sambal merah.
Palet warna hangat: merah #B82F11, oranye #E38A3C, krem #EFECDE. Sentuhan tema
bandara halus: pesawat kertas kecil dan garis putus-putus landasan di latar.
Teks besar "PENTOL PK BANDARA" di atas, subjudul "Pesan Online, Langsung
WhatsApp!", dan ruang kosong di bawah untuk QR code. Pencahayaan cerah,
komposisi rapi, mouthwatering, cocok untuk promo kuliner.
```

## 2) 🪧 Spanduk / Banner Gerobak (lanskap, mis. 2x1 m)
```
Desain spanduk horizontal untuk gerobak kaki lima, rasio 2:1, ramai dan
mengundang. Kiri: maskot kartun penjual pentol berlari membawa pentol berkuah.
Tengah-atas: judul besar "PENTOL PK BANDARA" gaya bold, subjudul "Gurih •
Kenyal • Sambal Nampol". Kanan: kotak putih besar sebagai tempat menempel QR
code dengan tulisan "SCAN & PESAN ONLINE". Warna dominan merah #B82F11 dan
oranye #E38A3C dengan aksen krem, motif garis landasan tipis. Ada ikon pesawat
kecil. Ilustrasi vektor bersih, teks mudah dibaca dari jauh, tema bandara.
```

## 3) 🍽️ Poster Feed / Katalog (persegi 1:1)
```
Poster promo makanan persegi 1:1 untuk Instagram/Facebook. Menampilkan foto
gaya ilustrasi beberapa varian pentol: pentol kriwil, pentol daging, tahu
bakso, disajikan dengan kuah dan sambal. Judul "PAKET & COMBO HEMAT" dengan
badge "HEMAT" dan "TERLARIS". Warna merah #B82F11, oranye #E38A3C, krem
#EFECDE. Maskot penjual pentol di pojok. Tema bandara halus (pesawat kecil).
Ruang untuk harga dan "Pesan via WhatsApp". Gaya cerah, menggugah selera.
```

## 📌 Setelah dapat gambarnya
1. Buka **[canva.com](https://canva.com)** (gratis)
2. Upload gambar hasil generate + file **`qr-pentol.png`** (ada di folder ini)
3. Taruh QR di ruang kosong yang udah disiapin, tambahkan:
   - Jam buka: **15.00 – 22.00 WITA**
   - "Scan untuk lihat menu & pesan"
4. Untuk gerobak: export PDF → cetak di percetakan (spanduk/stiker)
5. Untuk WA: export PNG → posting di Status

> Tips: QR code jangan terlalu kecil di spanduk (minimal 10x10 cm biar gampang di-scan).
